第一部分

觀念摘要

1. 四個基本方程與自然變數

封閉系統、只有 \(P\)–\(V\) 功時，四個能量函數的全微分（筆記裡的「四大天王」）：

函數定義基本方程自然變數
內能 \(U\)—\(dU = T\,dS - P\,dV\)\(S,\ V\)
焓 \(H\)\(H = U + PV\)\(dH = T\,dS + V\,dP\)\(S,\ P\)
Helmholtz 自由能 \(A\)\(A = U - TS\)\(dA = -S\,dT - P\,dV\)\(T,\ V\)
Gibbs 自由能 \(G\)\(G = H - TS\)\(dG = -S\,dT + V\,dP\)\(T,\ P\)

熱力學關係式（直接從上表讀出係數）：\(T = \left(\dfrac{\partial U}{\partial S}\right)_V = \left(\dfrac{\partial H}{\partial S}\right)_P\)，\(P = -\left(\dfrac{\partial U}{\partial V}\right)_S = -\left(\dfrac{\partial A}{\partial V}\right)_T\)，\(V = \left(\dfrac{\partial H}{\partial P}\right)_S = \left(\dfrac{\partial G}{\partial P}\right)_T\)，\(S = -\left(\dfrac{\partial A}{\partial T}\right)_V = -\left(\dfrac{\partial G}{\partial T}\right)_P\)。

熱力學方塊（講義的記法）
畫一個正方形：四個邊放能量函數 \(U, H, G, A\)，四個角放變數 \(S, P, T, V\)（例如邊上依序 \(A\)、\(G\)、\(H\)、\(U\)；角落 \(V, T\) 在 \(A\) 兩側、\(T, P\) 在 \(G\) 兩側、\(P, S\) 在 \(H\) 兩側、\(S, V\) 在 \(U\) 兩側）。
兩條對角線各畫一個箭頭：從 \(S\) 指向 \(T\)、從 \(P\) 指向 \(V\)。
原則：能量函數兩旁的兩個角是「微分項」，各自斜對面的角是「係數」；從微分項到係數順著箭頭為「＋」，逆著為「－」。
例：\(G\) 兩旁是 \(T\)、\(P\)；\(T\) 的對角是 \(S\)（\(T\to S\) 逆箭頭，\(-S\,dT\)），\(P\) 的對角是 \(V\)（\(P\to V\) 順箭頭，\(+V\,dP\)），所以 \(dG = -S\,dT + V\,dP\)。

2. Maxwell 關係式

四個基本方程都是恰當微分，交叉偏導數相等，得到四條 Maxwell 關係式。式子裡沒有 \(U, H, A, G\)，只剩 \(T, S, P, V\)：

\( \left(\dfrac{\partial T}{\partial V}\right)_S = -\left(\dfrac{\partial P}{\partial S}\right)_V \qquad \left(\dfrac{\partial T}{\partial P}\right)_S = \left(\dfrac{\partial V}{\partial S}\right)_P \)
\( \left(\dfrac{\partial S}{\partial V}\right)_T = \left(\dfrac{\partial P}{\partial T}\right)_V \qquad \left(\dfrac{\partial S}{\partial P}\right)_T = -\left(\dfrac{\partial V}{\partial T}\right)_P \)

3. 可量測的材料性質

性質定義與熵的關係
定容熱容 \(C_V\)\(\left(\dfrac{\partial U}{\partial T}\right)_V\)\(\left(\dfrac{\partial S}{\partial T}\right)_V = \dfrac{C_V}{T}\)
定壓熱容 \(C_P\)\(\left(\dfrac{\partial H}{\partial T}\right)_P\)\(\left(\dfrac{\partial S}{\partial T}\right)_P = \dfrac{C_P}{T}\)
體膨脹係數 \(\alpha\)\(\dfrac{1}{V}\left(\dfrac{\partial V}{\partial T}\right)_P\)\(\left(\dfrac{\partial S}{\partial P}\right)_T = -V\alpha\)
等溫壓縮係數 \(\beta\)\(-\dfrac{1}{V}\left(\dfrac{\partial V}{\partial P}\right)_T\)\(\left(\dfrac{\partial P}{\partial T}\right)_V = \dfrac{\alpha}{\beta}\)

4. 兩個數學工具

循環關係（講義叫 UDIO：Upstairs-Downstairs-Inside-Out；筆記叫「風水輪流轉」）：對任意三個變數 \(x, y, z\)，

\( \left(\dfrac{\partial x}{\partial y}\right)_z \left(\dfrac{\partial y}{\partial z}\right)_x \left(\dfrac{\partial z}{\partial x}\right)_y = -1 \)

實際用法：要求的偏導數＝負號 × 湊出同樣分子分母的兩個偏導數相除。

恰當微分判別：若 \(dZ = M\,dx + N\,dy\) 是全微分，則 \(\left(\dfrac{\partial M}{\partial y}\right)_x = \left(\dfrac{\partial N}{\partial x}\right)_y\)。

解題口訣
① 看到 \(S\) 對 \(T\) 偏微 → 填 \(C/T\)（定 \(V\) 用 \(C_V\)，定 \(P\) 用 \(C_P\)）。
② 看到 \(S\) 對 \(V\) 或 \(P\) 偏微 → 用 Maxwell 換成 \(P, V, T\)；對壓力偏微要加負號。
③ 換出來的 \(P, V, T\) 偏導數，能用 \(\alpha, \beta\) 就用；不能就先用循環關係湊成 \(\alpha, \beta\)。
④ 下標固定 \(S\) 的偏導數，先看能不能直接化簡，不行就用循環關係把 \(S\) 移出下標。
