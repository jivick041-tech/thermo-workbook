第一部分

先認識主角：每個符號在說什麼

熱力學的式子看起來很嚇人，其實只是在描述幾個主角之間的關係。先把主角認識清楚，後面的推導就只是「換個角度描述同一件事」。

想像一個系統：例如一個裝了氣體、上面有活塞的罐子。罐子以外的一切叫外界。罐子裡有非常非常多的小粒子（原子或分子），一直在跑來跑去、互相碰撞。

看得到、量得到的狀態

\(T\)溫度
粒子跑跳得有多激烈。
像操場上的小朋友：下課時跑來跑去（溫度高），上課時安靜坐好（溫度低）。
單位：K（克耳文）＝ °C + 273.15
\(P\)壓力
粒子撞牆壁的力道，平均攤在每單位面積上。
很多人一起擠一扇門，門被推的感覺。人越多、推越用力，壓力越大。
單位：Pa（帕）＝ N/m²；1 atm ≈ 1.013 × 10⁵ Pa
\(V\)體積
系統佔了多大的空間。
罐子裡活塞以下那一段空間有多大。
單位：m³；1 cm³ = 10⁻⁶ m³

能量家族

\(U\)內能
系統裡面藏著的全部能量。
像存錢筒裡的錢：包括粒子跑動的能量，加上粒子之間互相拉扯的能量。我們只在乎「存錢筒裡的錢變多還是變少」（\(\Delta U\)）。
單位：J（焦耳）
\(q\)熱
因為溫度不同，自己流進或流出系統的能量。
熱湯放在桌上，熱會自己流到空氣裡。熱是「流動中的能量」，不是系統「擁有」的東西。
單位：J；\(q > 0\) 表示系統吸熱
\(w\)功
系統推動外界（或被外界推）時交換的能量。
氣體推動活塞往上，就是系統對外界作功，存錢筒的錢會減少。本講義跟 Gaskell 一樣：\(w > 0\) 表示系統對外界作功。
單位：J；推活塞的功 \(= P\,dV\)
\(H\)焓
\(H = U + PV\)：內能，再加上「為了佔住這個空間所付出的能量」。
走進一間擠滿人的教室，你除了自己的力氣（\(U\)），還得把別人推開才有位置站（\(PV\)）。在固定壓力下（例如在大氣中做實驗），系統吸的熱剛好就等於 \(H\) 的增加量。
單位：J
\(S\)熵
「亂」的程度：同一個樣子，粒子有多少種排法。
整理好的書桌只有一種排法；亂七八糟的書桌有超多種排法。沒人去管時，房間只會越來越亂，不會自己變整齊。大自然也一樣，熵總是傾向增加。
單位：J/K
\(A\)Helmholtz 自由能
\(A = U - TS\)：在固定溫度、固定體積下，真正「拿得出來用」的能量。
存錢筒裡的錢（\(U\)）不能全部花掉，有一部分被「亂度」綁住了（\(TS\)）。扣掉綁住的部分，剩下的才是零用錢。
單位：J
\(G\)Gibbs 自由能
\(G = H - TS\)：在固定溫度、固定壓力下，拿得出來用的能量；也是判斷「會不會自己發生」的分數。
像球放在山坡上：球會自己往低處滾。在定溫定壓下，變化會自己往 \(G\) 變小的方向走，\(G\) 最低的地方就是最穩定的狀態（平衡）。材料科學最常用的就是它。
單位：J

材料的「個性」：實驗量得到的性質

\(C_P,\ C_V\)熱容
要讓溫度升高 1 度，需要給多少熱。
像食量：有人吃一碗就飽，有人要吃三碗。\(C_V\) 是體積固定時的食量；\(C_P\) 是壓力固定時的食量。壓力固定時系統會膨脹、要推開外界，多花一點能量，所以 \(C_P \ge C_V\)。
單位：J/(mol·K)
\(\alpha\)體膨脹係數
溫度升高 1 度，體積變大幾分之幾。
夏天鐵軌會變長，所以鐵軌之間要留縫。\(\alpha\) 越大，越「怕熱」、越會脹。
單位：K⁻¹
\(\beta\)等溫壓縮係數
壓力增加 1 單位，體積縮小幾分之幾。
捏海綿很容易扁（\(\beta\) 大）；捏石頭幾乎不動（\(\beta\) 小）。氣體像海綿，固體像石頭。
單位：Pa⁻¹
一句話記住四個能量函數
\(U\)：全部的能量。\(H\)：全部的能量＋佔位置的能量。
\(A\)：定溫、定容時可用的能量。\(G\)：定溫、定壓時可用的能量，越低越穩定。
第二部分

數學工具箱

這個單元會用到的數學只有下面這幾招。每一招都附一個例子；推導練習裡標了「用到的數學」，忘記時可以點回來看。

M1　\(d\)：一點點的變化

\(\Delta T\) 是「變了多少」（例如從 300 K 到 310 K，\(\Delta T = 10\) K）。\(dT\) 是「變了非常非常小的一點點」。

為什麼要用 \(dT\)？因為很多量在變化過程中一直在改變（例如加熱時熱容也在變），只有切成很小很小的一段，才能把它當成固定值來算，最後再全部加起來（積分，見 M6）。

M2　導數：變化的比例（斜率）

\(\dfrac{dy}{dx}\) 的意思是：「\(x\) 變一點點時，\(y\) 跟著變多少倍」。
例：走路的距離 \(s\) 對時間 \(t\) 的導數 \(\dfrac{ds}{dt}\) 就是速度。
例：\(\dfrac{dV}{dT}\) 就是「溫度升 1 度，體積變大多少」。

M3　偏微分：只動一個，其他固定

如果一個量同時受好幾個變數影響，\(\left(\dfrac{\partial y}{\partial x}\right)_z\) 的意思是：把 \(z\) 固定不動，只改變 \(x\)，看 \(y\) 變多少。
右下角的小字（下標）就是「被固定的那個」。
例：長方形面積 \(Z = xy\)。
把寬 \(y\) 固定，只改長 \(x\)：\(\left(\dfrac{\partial Z}{\partial x}\right)_y = y\)（長每多 1，面積多一條寬）。
把長 \(x\) 固定，只改寬 \(y\)：\(\left(\dfrac{\partial Z}{\partial y}\right)_x = x\)。
熱力學例：\(\left(\dfrac{\partial V}{\partial T}\right)_P\) ＝ 壓力固定時，溫度升 1 度體積變多少。下標不同，答案就不同！氣體在定壓下加熱會膨脹，但在定容（\(V\) 固定）下，體積當然不會變。

M4　全微分：所有變數一起動

當 \(x\) 和 \(y\) 都變一點點，\(Z\) 的總變化 ＝（只動 \(x\) 造成的）＋（只動 \(y\) 造成的）：
\(dZ = \left(\dfrac{\partial Z}{\partial x}\right)_y dx + \left(\dfrac{\partial Z}{\partial y}\right)_x dy\)
例：長方形 \(Z = xy\)，長多了 \(dx\)、寬多了 \(dy\)：\(dZ = y\,dx + x\,dy\)。
想像畫圖：原本的長方形右邊多了一條（面積 \(y\,dx\)），上面多了一條（面積 \(x\,dy\)）；角落那一小塊 \(dx\,dy\) 小到可以忽略。
熱力學例：把熵看成溫度和體積的函數 \(S(T,V)\)：\(dS = \left(\dfrac{\partial S}{\partial T}\right)_V dT + \left(\dfrac{\partial S}{\partial V}\right)_T dV\)。

M5　常用的微分規則

規則式子例子
常數\(d(c) = 0\)\(R\) 是常數，\(dR = 0\)
常數倍\(d(cx) = c\,dx\)\(d(RT) = R\,dT\)
次方\(d(x^n) = n x^{n-1}dx\)\(d(T^2) = 2T\,dT\)；\(d(1/T) = -\dfrac{dT}{T^2}\)
自然對數\(d(\ln x) = \dfrac{dx}{x}\)\(d(\ln P) = \dfrac{dP}{P}\)
乘積\(d(uv) = u\,dv + v\,du\)\(d(PV) = P\,dV + V\,dP\)；\(d(TS) = T\,dS + S\,dT\)
商\(d\!\left(\dfrac{u}{v}\right) = \dfrac{v\,du - u\,dv}{v^2}\)\(d\!\left(\dfrac{G}{T}\right) = \dfrac{dG}{T} - \dfrac{G\,dT}{T^2}\)

乘積規則就是 M4 長方形的例子：兩個都在變，所以兩邊各多一條。

M6　積分：把一點點加起來

積分 \(\displaystyle\int_a^b\) 就是把 \(a\) 到 \(b\) 之間每一小段的變化全部加起來，得到總變化。
要加的東西結果熱力學哪裡用到
\(\displaystyle\int_{x_1}^{x_2} c\,dx\)\(c\,(x_2 - x_1)\)固體加壓 \(\Delta S = -V\alpha\,\Delta P\)
\(\displaystyle\int_{x_1}^{x_2} \dfrac{dx}{x}\)\(\ln\dfrac{x_2}{x_1}\)理想氣體 \(\Delta S = -R\ln\dfrac{P_2}{P_1}\)
\(\displaystyle\int_{x_1}^{x_2} \dfrac{dx}{x^2}\)\(\dfrac{1}{x_1} - \dfrac{1}{x_2}\)van der Waals 氣體的 \(\Delta U\)

M7　自然對數 ln

\(\ln x\) 問的是：「\(e\)（約 2.718）要幾次方才會等於 \(x\)？」計算機上的 ln 鍵就是它。

常用性質：\(\ln 1 = 0\)；\(\ln(ab) = \ln a + \ln b\)；\(\ln\dfrac{a}{b} = \ln a - \ln b\)；\(\ln a^n = n\ln a\)。
常見數值：\(\ln 2 \approx 0.693\)，\(\ln 10 \approx 2.303\)，\(\ln 1000 = 3\ln 10 \approx 6.91\)。

M8　恰當微分：先後順序沒關係

如果 \(Z\) 是一個真正的函數（例如狀態函數 \(U, H, S, G\)），先對 \(x\) 偏微、再對 \(y\) 偏微，和反過來做，答案一定一樣。
例：\(Z = x^2 y\)。
先 \(x\) 後 \(y\)：\(\dfrac{\partial Z}{\partial x} = 2xy\)，再對 \(y\)：\(2x\)。
先 \(y\) 後 \(x\)：\(\dfrac{\partial Z}{\partial y} = x^2\)，再對 \(x\)：\(2x\)。兩個一樣 ✓

所以若 \(dZ = M\,dx + N\,dy\)，就有 \(\left(\dfrac{\partial M}{\partial y}\right)_x = \left(\dfrac{\partial N}{\partial x}\right)_y\)。Maxwell 關係式就是這樣來的。

M9　循環關係（風水輪流轉）

三個彼此相關的變數 \(x, y, z\)，三個偏導數「輪流」相乘一定等於 \(-1\)：
\(\left(\dfrac{\partial x}{\partial y}\right)_z \left(\dfrac{\partial y}{\partial z}\right)_x \left(\dfrac{\partial z}{\partial x}\right)_y = -1\)

記法：分子、分母、下標三個位置，\(x \to y \to z\) 輪流坐一次。

用理想氣體 \(PV = RT\)（1 mol）驗證：
\(\left(\dfrac{\partial P}{\partial T}\right)_V = \dfrac{R}{V}\)，\(\left(\dfrac{\partial T}{\partial V}\right)_P = \dfrac{P}{R}\)，\(\left(\dfrac{\partial V}{\partial P}\right)_T = -\dfrac{RT}{P^2}\)
相乘：\(\dfrac{R}{V}\cdot\dfrac{P}{R}\cdot\left(-\dfrac{RT}{P^2}\right) = -\dfrac{RT}{PV} = -1\) ✓

實際怎麼用：想求的偏導數不好算時，把式子移項：
\(\left(\dfrac{\partial P}{\partial T}\right)_V = -\dfrac{(\partial V/\partial T)_P}{(\partial V/\partial P)_T}\)：負號 × 分子分母各換成一個「好量」的偏導數。

M10　單位換算與科學記號

\(1\ \text{J} = 1\ \text{Pa}\cdot\text{m}^3\)：壓力乘體積就是能量，所以算 \(PV\) 或 \(V\alpha\,\Delta P\) 時，體積一定要用 m³、壓力用 Pa。
\(1\ \text{cm}^3 = 10^{-6}\ \text{m}^3\)；\(1\ \text{atm} = 1.01325\times10^5\ \text{Pa}\)；\(1\ \text{kJ} = 1000\ \text{J}\)。
科學記號相乘：數字乘數字、次方相加，例如 \((7\times10^{-6})(5\times10^{-5}) = 35\times10^{-11} = 3.5\times10^{-10}\)。
