第一部分

觀念摘要

白話說：相圖是「每個溫度、每個成分，G 最低的是誰」的地圖

單元 7 是一種物質，比較固、液、氣的 G。這個單元是兩種元素 A、B，所以每一相的 G 會隨成分改變，要畫成 G–X 曲線來比較。相圖上的每一條線，都是從 G–X 曲線「讀」出來的。

G–X 曲線怎麼畫？

\(G = X_AG_A^\circ + X_BG_B^\circ + \Delta G^M\)

前兩項是一條直線（沒混合時的平均），\(\Delta G^M\) 是往下凹的混合效果（單元 9）。正規溶液：

\(\Delta G^M = RT(X_A\ln X_A + X_B\ln X_B) + \Omega X_AX_B\)

  • 第一項（熵）永遠是負的，溫度越高越負，想讓大家混在一起。
  • 第二項（焓）：Ω > 0 時是正的，想把 A、B 分開；跟溫度無關。
  • 高溫時熵贏，曲線一路往下凹，單一相；低溫時焓贏，曲線中間鼓起來，分成兩相。

公切線法則：兩相平衡

單元 9：G–X 曲線上一點的切線，左右截距就是 \(\mu_A\)、\(\mu_B\)。兩相平衡時，A 在兩相的 μ 要相等，B 也要相等，所以兩相的切線必須是同一條（公切線）。公切點的成分就是兩相的平衡成分。

成分落在兩個公切點之間的合金，會分成這兩相，比例用槓桿法則：

\(f_\beta = \dfrac{X - X^\alpha}{X^\beta - X^\alpha}\)，\(f_\alpha = 1 - f_\beta\)

比喻：蹺蹺板。合金成分是支點，離哪一相比較近，那一相就比較多。

互溶間隙（miscibility gap）

Ω > 0 的正規溶液，低溫時會分成兩個成分不同的同一種結構（α₁ + α₂）。把各溫度的公切點連起來就是相圖上的「圓頂」：

  • 頂點（臨界溫度）：\(T_c = \dfrac{\Omega}{2R}\)，在 \(X = 0.5\)。
  • binodal（實線）：公切點，兩相平衡的界線。
  • spinodal（虛線）：\(\dfrac{d^2G}{dX^2} = 0\) 的點。在 spinodal 裡面，任何微小的成分波動都會讓 G 下降，所以會自發、均勻地分解（spinodal decomposition），不需要成核。

固、液兩相的相圖

  • 同型（isomorphous）：A、B 固態和液態都完全互溶（如 Cu–Ni、Ge–Si）。理想時，液相線和固相線完全由兩個元素的熔點和熔化熱決定。
  • 共晶（eutectic）：固態幾乎不互溶、液態完全互溶（如 Pb–Sn 銲錫、Al–Si）。加一點 B 會讓 A 的熔點下降，兩條下降的液相線交在一點，就是共晶點，那裡的熔點最低。

理想溶液、固態不互溶時，A 的液相線是：

\(\ln X_A^l = -\dfrac{\Delta H_{m,A}}{R}\left(\dfrac{1}{T} - \dfrac{1}{T_{m,A}}\right)\)

這就是「加鹽讓冰的熔點下降」的同一個式子。
