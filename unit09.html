第一部分

觀念摘要

白話說：溶液就是「原子層級的混合」

合金、熔融金屬、玻璃、鹽水都是溶液。A 和 B 混在一起後，每一種原子「想跑出去的程度」會改變。熱力學用活性 a 來描述這件事：

\(a_i = \dfrac{p_i}{p_i^\circ}\)（溶液上方 i 的蒸氣壓 ÷ 純 i 的蒸氣壓）

比喻：純的 B 在自己家（純 B）裡「想出門的程度」是 1。搬到 A 的家裡住之後，如果室友很友善（A、B 互相吸引），就比較不想出門，\(a < X\)；如果室友很討厭（互相排斥），就更想出門，\(a > X\)。

兩條直線：Raoult 與 Henry

  • Raoult 定律（理想溶液）：\(p_i = X_ip_i^\circ\)，也就是 \(a_i = X_i\)。
  • Henry 定律（很稀的溶質）：\(p_i = k_iX_i\)，也就是 \(a_i = \gamma_i^\circ X_i\)，\(\gamma_i^\circ\) 是常數。
  • 活性係數 \(\gamma_i = a_i/X_i\)：\(\gamma = 1\) 理想；\(\gamma > 1\) 正偏差（互相排斥）；\(\gamma < 1\) 負偏差（互相吸引）。

部分莫耳量與 Gibbs–Duhem 方程式

部分莫耳量 \(\bar{Q}_i\)：往一大桶溶液裡加 1 mol 的 \(i\)，總量 \(Q'\) 增加多少。例如水和酒精各 50 mL 混合，總體積不到 100 mL，因為每種分子在混合物裡「佔的體積」（部分莫耳體積）跟純的時候不一樣。

  • 總量由部分莫耳量組成：\(Q = X_A\bar{Q}_A + X_B\bar{Q}_B\)。
  • 切線截距法：在 \(Q\)–\(X_B\) 曲線上某一點畫切線，切線在 \(X_B = 0\) 和 \(X_B = 1\) 的截距，就是 \(\bar{Q}_A\) 和 \(\bar{Q}_B\)。
  • Gibbs–Duhem：\(X_A\,d\bar{Q}_A + X_B\,d\bar{Q}_B = 0\)。兩個成分的部分莫耳量不能各自亂變，一個上升另一個就要下降。所以只要量到一個成分的活性，另一個就能算出來。

混合的熱力學量

一般溶液理想溶液正規溶液（regular）
\(\Delta G^M\)\(RT(X_A\ln a_A + X_B\ln a_B)\)\(RT(X_A\ln X_A + X_B\ln X_B)\)理想值 \(+\ \Omega X_AX_B\)
\(\Delta H^M\)量測0\(\Omega X_AX_B\)
\(\Delta S^M\)量測\(-R(X_A\ln X_A + X_B\ln X_B)\)與理想相同
活性係數\(\gamma_i = a_i/X_i\)\(\gamma = 1\)\(RT\ln\gamma_A = \Omega X_B^2\)

超額量（excess）：真實值減去理想值，例如 \(G^{xs} = \Delta G^M - \Delta G^{M,id} = RT(X_A\ln\gamma_A + X_B\ln\gamma_B)\)。

Ω 從哪裡來？（準化學模型）

把溶液想成原子排在格子上，每個原子有 z 個鄰居。A–A、B–B、A–B 三種鍵的能量分別是 \(\omega_{AA}\)、\(\omega_{BB}\)、\(\omega_{AB}\)。隨機混合時：

\(\Omega = zN_0\left[\omega_{AB} - \tfrac{1}{2}(\omega_{AA} + \omega_{BB})\right]\)

  • \(\Omega < 0\)：A–B 鍵比平均強，喜歡異類鄰居 → 放熱混合、負偏差，容易形成化合物或有序結構。
  • \(\Omega > 0\)：喜歡同類 → 吸熱混合、正偏差，低溫時會分成兩相（單元 10 的互溶間隙）。
  • \(\Omega = 0\)：理想溶液。
