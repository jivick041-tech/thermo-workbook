第一部分

觀念摘要

白話說：真實氣體不是「理想」的

理想氣體 \(PV = nRT\) 假設兩件事：①分子本身不佔體積、②分子之間沒有吸引力。壓力低、溫度高時，分子離得很遠，這兩個假設差不多成立；壓力一高、溫度一低，分子擠在一起，就不能忽略了。

比喻：理想氣體像一群「透明、互不理睬」的人在大廣場上走；真實氣體則是在擠滿人的捷運車廂裡，每個人都佔位置（體積），還會彼此拉來拉去（吸引力）。

壓縮因子 Z：偏離理想多少？

\(Z = \dfrac{PV}{RT}\)（1 mol）

  • \(Z = 1\)：表現得像理想氣體。
  • \(Z < 1\)：比理想氣體好壓縮，吸引力在主導（中等壓力常見）。
  • \(Z > 1\)：比理想氣體難壓縮，分子本身的體積在主導（很高壓時）。

凡德瓦（van der Waals）方程式：把兩個缺點補回去

\(\left(P + \dfrac{a}{V^2}\right)(V - b) = RT\)

修正項物理意義白話
\(V - b\)\(b\)：1 mol 分子本身佔掉的體積真正能讓分子跑來跑去的空間比容器小
\(P + a/V^2\)\(a\)：分子間吸引力的強度撞牆前被後面的分子往回拉，所以量到的壓力比較小，要補回來

溫度高於臨界溫度 \(T_c\) 時，不管壓多大都不會變成液體；低於 \(T_c\) 時，壓縮到某個壓力就會開始凝結，曲線上會出現液、氣共存的水平段。剛好在 \(T_c\) 時，曲線有一個「平的轉折點」，就是臨界點：

\(V_c = 3b\)，\(T_c = \dfrac{8a}{27Rb}\)，\(P_c = \dfrac{a}{27b^2}\)，\(Z_c = \dfrac{P_cV_c}{RT_c} = \dfrac{3}{8}\)

對應狀態定律：用「相對值」看，所有氣體長得一樣

把壓力、體積、溫度都除以臨界值，叫做對比（減縮）變數：\(P_r = P/P_c\)、\(V_r = V/V_c\)、\(T_r = T/T_c\)。用這些變數寫，凡德瓦方程式裡的 \(a\)、\(b\) 會消失，所以只要 \(T_r\)、\(P_r\) 一樣，不同氣體的 Z 就差不多一樣。這就是工程上「通用壓縮因子圖」的原理。

氣體混合：分壓與化學位能

  • 道爾頓分壓定律：\(p_i = X_i P\)，每種氣體好像自己獨佔整個容器。
  • 部分莫耳量 \(\bar{Q}_i = (\partial Q'/\partial n_i)_{T,P,n_j}\)：在一大桶混合物裡多加 1 mol 的 \(i\)，總量 \(Q'\) 增加多少。部分莫耳 Gibbs 自由能就是化學位能 \(\mu_i\)。
  • 理想氣體：\(\mu_i = G_i^\circ + RT\ln p_i\)（\(p_i\) 用 atm）。
  • 理想氣體混合：\(\Delta G^{M} = RT\sum n_i\ln X_i < 0\)（一定會自己混合）、\(\Delta H^{M} = 0\)、\(\Delta S^{M} = -R\sum n_i\ln X_i > 0\)。

逸壓（fugacity）f：真實氣體的「有效壓力」

理想氣體 \(dG = RT\,d\ln P\)。真實氣體為了保留這麼簡單的式子，就把 \(P\) 換成「逸壓」\(f\)：

\(dG = RT\,d\ln f\)，且 \(P \to 0\) 時 \(f/P \to 1\)

\(f/P\) 叫逸壓係數。\(f < P\)：吸引力讓分子「沒那麼想跑走」；\(f > P\)：分子體積讓它「更想跑走」。標準狀態是「\(f = 1\) atm 時的理想氣體」。
