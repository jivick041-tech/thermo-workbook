第一部分

觀念摘要

白話說：熱容是材料的「食量」，而且會隨溫度改變

單元 1 說過，熱容是「升溫 1 度要吃多少熱」。這一章要回答三個問題：熱容從哪裡來？溫度改變時，反應熱 \(\Delta H\) 和熵 \(\Delta S\) 怎麼跟著變？熵有沒有「零點」？

熱容的經驗規則與理論

名稱內容適用範圍
Dulong–Petit（1819）固體元素的 \(c_V \approx 3R \approx 24.9\ \text{J/(mol·K)}\)室溫附近、不是所有材料
Kopp（1865）化合物的 \(c_V \approx\) 組成元素的 \(c_V\) 加總室溫附近
Einstein 模型每個原子是 3 個方向、單一頻率 \(\nu\) 的量子振子：
\(c_V = 3R\left(\dfrac{\theta_E}{T}\right)^2\dfrac{e^{\theta_E/T}}{(e^{\theta_E/T}-1)^2}\)，\(\theta_E = h\nu/k\)		高溫 → \(3R\)；低溫降到 0 太快
Debye 模型振動頻率從 0 到 \(\nu_D\) 都有（像連續固體的彈性波）；低溫時 \(c_V = 1943\left(\dfrac{T}{\theta_D}\right)^3\ \text{J/(mol·K)}\)（\(T^3\) 定律）低溫很準

焓與溫度：焓–溫度圖

\(H\) 沒有絕對值，所以約定：穩定狀態的元素在 298 K 時 \(H = 0\)。於是化合物在 298 K 的 \(H\) 就等於它的生成熱，例如 \(H_{PbO,298} = \Delta H_{f,PbO,298} = -219{,}000\ \text{J/mol}\)。

要算別的溫度的反應熱，就在焓–溫度圖上「繞路」（Hess 定律，\(H\) 是狀態函數）：反應物從 \(T\) 降到 298 K → 在 298 K 反應 → 產物從 298 K 升回 \(T\)。中間如果有熔化或相變，要加上（或減去）潛熱。

\(\Delta H_T = \Delta H_{298} + \displaystyle\int_{298}^{T}\Delta c_P\,dT\)，\(\Delta c_P = \sum c_P(\text{產物}) - \sum c_P(\text{反應物})\)

熵也一樣：\(\Delta S_T = \Delta S_{298} + \displaystyle\int_{298}^{T}\dfrac{\Delta c_P}{T}dT\)，遇到相變加上 \(\Delta H_{tr}/T_{tr}\)；然後 \(\Delta G_T = \Delta H_T - T\Delta S_T\)。

第三定律

Nernst：溫度接近 0 K 時，系統的熵趨近一個常數。Planck 補充：處在完全內部平衡的純物質（完美晶體），0 K 時熵為 0。因為 0 K 時只剩一種排法（基態），\(S = k\ln1 = 0\)。所以熵有絕對值：

\(S_T = \displaystyle\int_0^T\dfrac{c_P}{T}dT\)（中間有相變時加上 \(\Delta H_{tr}/T_{tr}\)）

玻璃、有缺陷或排列不規則的晶體，在 0 K 仍留有一點熵（殘餘熵），因為它們不是完全平衡的狀態。

過冷液體凝固（講義重點題型）
過冷液體在熔點以下自己凝固，是不可逆過程。算系統的 \(\Delta S\) 要繞可逆路徑：液體升溫到熔點 → 在熔點可逆凝固 → 固體降溫回來。外界（恆溫槽）的熵變 = \(-\Delta H_{系統}/T_{槽}\)。兩者相加 > 0，證明它是自發的。
